# Security Policy

## Reporting a vulnerability

If you find a security issue in Fury — for example, a path that exposes a user's Minecraft authentication tokens or a vulnerability in the launcher or proxy — report it privately rather than opening a public issue.

Email: **hadex9337@gmail.com**

Please include a description of the issue, its impact, steps to reproduce, and the Fury version or commit hash you tested.

## Scope

- The Fury launcher and proxy in this repository.
- Local user data, especially Minecraft authentication tokens and API keys.

## Out of scope

- Issues that require physical access to the victim's machine.
- Vulnerabilities in upstream dependencies — report those upstream.
- Cheats, ban evasion, or game-rule circumvention on Hypixel or other servers.

Please allow a reasonable disclosure window, suggested 90 days or until a fix ships.
